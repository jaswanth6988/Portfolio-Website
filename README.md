# 🚀 Jaswanth Srighakollapu — Portfolio

A futuristic, premium portfolio website built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**.

## ✨ Features

- 🎨 **Dark/Light Mode** — Seamless theme switching with beautiful color palettes
- 🌊 **Scroll Animations** — Smooth reveal animations powered by Framer Motion
- 🪟 **Glassmorphism Design** — Frosted glass cards with subtle gradients
- 📱 **Fully Responsive** — Looks incredible on every device
- 🔒 **Contact Form API** — Built-in Next.js API route for form submissions
- ⚡ **Lightning Fast** — Optimized with Next.js static export
- 🎯 **SEO Ready** — Complete metadata configuration

## 🛠️ Tech Stack

| Technology | Purpose |
|-----------|---------|
| Next.js 14 | React framework with App Router |
| Tailwind CSS 3.4 | Utility-first CSS |
| Framer Motion | Animation library |
| Lucide React | Beautiful icon set |
| next-themes | Dark/light mode |

## 🏃 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 📁 Project Structure

│   ├── layout.js          # Root layout (fonts, theme)
│   ├── page.js            # Main page (all sections)

│   ├── providers.js       # Theme provider
│   └── api/contact/       # Contact form API
├── components/
│   ├── Navbar.jsx         # Floating glass navigation
│   ├── Hero.jsx           # Cinematic hero section
│   ├── About.jsx          # Bio, stats & platforms

│   ├── Skills.jsx         # Categorized tech grid
│   ├── Projects.jsx       # Bento project cards
│   ├── Certifications.jsx # Certificate showcase
│   ├── Blog.jsx           # Blog previews
│   ├── Contact.jsx        # Contact form & socials
│   ├── Footer.jsx         # Minimal footer
│   ├── ThemeToggle.jsx    # Dark/light switch
│   └── ui/                # Reusable primitives
├── lib/
│   └── data.js            # All portfolio data
